Yalla Viral Website — Full Repository Guide

Repo: mostfa12abd-dotcom/yalla-viral-website  •  Live: https://yalla-viral-website.vercel.app  •  202 files

Stack: Vite 5 + React 18 + TypeScript + Tailwind CSS v4 + shadcn/ui (New York) + framer-motion + wouter. Dark-mode only. Deploys automatically from main via Vercel.

Commands: pnpm run dev (local server) • pnpm run typecheck • pnpm run build (outputs dist/)
